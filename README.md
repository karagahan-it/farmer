# TopoGrade / Farmer

Android MVP for offline topographic surveying, terrain modeling and grading workflows.

## MVP
- Offline projects
- XYZ survey points
- CSV import/export
- TIN terrain model
- Contour generation
- Persian-first UI

## Roadmap
GNSS/RTK + NTRIP, MapLibre offline maps, grading design, cut/fill and field guidance.

> Clean-room implementation; no proprietary APK source/assets are copied.
