# TopoGrade Roadmap

## Phase 1 — Survey MVP
Status: **in progress**

Implemented:
- Project creation and local persistence
- Manual XYZ point collection
- Elevation statistics
- Initial point-map visualization
- Geometry foundation

Next:
- Edit/delete points
- CSV import/export UI
- Project metadata and coordinate-system selection
- Proper Delaunay triangulation
- Contour rendering

## Phase 2 — Mapping
- MapLibre Native
- Offline tile packs
- WGS84 / UTM transforms
- Project boundary and layer manager

## Phase 3 — RTK
- Bluetooth / USB / TCP receiver adapters
- NMEA parser
- NTRIP client
- RTCM stream
- FIX / FLOAT / DGPS status and accuracy dashboard

## Phase 4 — Grading
- Design plane
- Single / dual slope
- Existing-vs-design surface
- Cut/fill heatmap
- Volume reports
- Field guidance

## Phase 5 — Machine integration
Only after safety engineering, calibration, watchdogs, interlocks and controlled field validation.
